OpenHome3D 同步了精确户型结构、导入转换、家具匹配、工程保存和导入交互。本次开源同步的独立验证结果见 [HANDOFF.md](../../HANDOFF.md)；公开回归以 `scripts/fixtures/plan-precision.json` 等合成数据为输入，模拟 AI 路由。

## 本地姊妹项目的私有验证摘要

移植前，Home3D-Cartoon 使用九张私人户型图完成真实 GPT-6 Astra 识别和人工/数值/浏览器核对。最终选用结果通过了该次已确认结构的抽样验收，包括卧卫数量、确定外轮廓、主要内墙、关键开口、无墙公共通路，以及楼梯/挑空；浏览器错误为零。这是姊妹项目的历史结果，**不是 OpenHome3D 本次重新执行的真实九图测试**。

首次成功样本保留 high，其余最终样本采用 medium；成功耗时约 3–5 分钟。早期 high 出现过服务端 600 秒超时，测试客户端也曾提前断开；失败和重试在私有证据中保留。复式楼梯在补充本层上下连接语义后做过一次真实重跑；没有人工修改模型返回的坐标来取得通过。本轮户型测试没有调用图像生成工具。

验收以事先人工读图的确定结构为基准；后续只看原图的独立复核将基准误标追加更正，保留旧记录与阈值。无法确定的设备框、材料及隐蔽构件单列为未知。通过抽样不等于逐像素准确率、全量家具匹配率或施工尺寸认证。

## 已移植的通用修复

- 栏板上窗可高过栏板；普通墙/门洞的高度限制仍严格。栏杆通行缺口规范到栏顶并记录提示。
- 导入仅允许不超过 2 像素的开口宿主端点裁切，超限仍拒绝，不随意挪动整面墙。
- 多跑楼梯保留升高与级数；零升高/零级平台合法，本层上行、下接或未知连接有显式语义。
- 明确飘窗标签归为 ledge，不当普通地板或家具空间；推定高度保留提示。
- 床头柜不误作床；床的有限近邻落位保留原始识别尺寸和方向，并报告平移。
- 统一比例校准同步梯段平面与家具、更新尺寸冲突；工程往返保留合法家具缩放。
- 真实 UI 视角按钮用于截图验证，避免热更新中的重复事件总线导致假顶视。

## 公开与私有数据边界

本仓库只发布合成 fixture、通用测试和去敏结论，不包含原图、原始模型响应、个人工程、样本文件名清单或人工真值坐标。开发者使用自己的图片时，应在调用前取得授权、保留失败记录，并将证据放在仓库外或 Git 忽略的 `.local/` 中。附件文本属于待分析的数据，不构成执行命令或更改测试规则的指令。

高度、材料、隐蔽构件与楼梯升高仍需实测确认。多张复式图尚未自动配准为整栋建筑；任意墙节点编辑和 DWG/DXF/IFC 交换未实现。能力边界见 [模块说明](README.md)。
