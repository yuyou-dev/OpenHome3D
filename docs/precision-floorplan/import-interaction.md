# 户型导入交互修复

原有大图可能被侧栏遮挡、关闭操作失效且背景仍能响应，识别进度也缺少独立等待界面。本轮同步顶层模态与完整导入流程，复用现有纸色、墨线、硬阴影和按钮组件。

## 交互决定

1. 点右下角原图打开独立顶层模态。图片等比完整显示；明确的「关闭」和 Esc 返回编辑器并恢复焦点。点击遮罩不会误关闭或操作背景。
2. 选择图片后立即显示置顶识别进度和等待时间，不使用虚假百分比。可「放弃识别」或 Esc；排队放弃只取消自己的等待，另有明确中止上一任务的独立操作。
3. 识别成功自动打开原图/解析叠加核对，不改当前方案。蓝色为空间与墙线、粉色门、黄色窗、虚线挑空；沿用与 3D 相同的几何数据。说明和不确定项单独滚动，图纸适应剩余高度。简化旧格式显示原图及空间尺寸，并明确其限制。
4. 黄色「导入」是最终提交，一次更新布局和原图，可撤销。「放弃导入」或 Esc 丢弃草稿。导入失败在弹窗内提示并保留草稿供重试。对已导入方案的日常核对仍使用「关闭」。

## 实现与验证

旧 lightbox 位于 `.ui-overlay` 的局部堆叠上下文，继承 `pointer-events:none`，单纯加大 z-index 无法解决。统一的 `PlanDialog` 通过 portal 挂到 body，以原生 `showModal()` 进入浏览器顶层，背景 inert；保留 `data-modal` 与编辑器快捷键约定。标题和操作区不随内容滚动，避免短屏下失去退出路径。

本仓库构建与验证结果统一记录在 [HANDOFF.md](../../HANDOFF.md)。浏览器门禁包括 `smoke:ui`、`smoke:interactions`、`smoke:project`、`smoke:ai-flow`、`audit:ui`、`smoke:precision:ui`。新增验证覆盖 1600×1000、390×844、390×500：

- 识别自动核对、导入前数据不变、放弃后重选同文件、最终导入。
- Cancel/Esc、排队取消不杀其他任务、迟到回复失效。
- 原图与叠加完整显示，操作区可见，背景点击、键盘、相机拖拽和滚轮被隔离。
- 原生焦点隔离、原图 Close/Esc 保留图片、导入后的结构编辑和撤销重做。

流程回归使用隔离浏览器与公开合成 fixture，模拟全部 AI 路由，不调用真实识别、不更换用户方案。截图默认写入系统临时目录；个人原图与生成工程只保留在 Git 忽略的 `.local/` 或仓库外。本次移植没有重跑私有九图，亦不构成完整辅助技术或 WCAG 合规审计。
