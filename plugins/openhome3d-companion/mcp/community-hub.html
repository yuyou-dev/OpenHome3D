第一次使用 GitHub

推荐最短路径：使用邮箱创建免费的 GitHub 个人账号。Google/Apple 登录不作为主流程，避免不同账号体系和授权页面带来的额外分支。

1
打开 GitHub 官方注册页只在 github.com 填写资料。OpenHome3D 和 Companion 都不会看到密码。
2
填写邮箱、密码和用户名用户名会成为你在 Discussion 和 Pull Request 中的公开署名。
3
完成验证码与邮箱验证验证码和验证邮件需要你本人完成，Codex 不会代填或读取。
4
建议开启双因素认证按照 GitHub 页面保存恢复码，这是保护账号的重要步骤。
5
回到 Codex 连接账号Codex 使用 GitHub CLI 的浏览器授权；无需把密码或令牌粘贴给项目。
